# 100% Udemy Sale-Off Courses Android App

This Android app allows users to access 100% sale-off Udemy courses for free. All courses are
fetched from a server and displayed in a list.

# Features

- List coupons (paging)
- Detailed info
- Share coupons as text and open in browser
- Enroll the course (web view)
- List enrolled courses (web view)
- Dark mode
- Fingerprint
- Touch image view

# Build from source

### Requirement
- Add at least 1 fingerprint into the android device to enable `Fingerprint` feature
- Language: Kotlin
- Android Studio: Flamingo 2022.2.1
- Gradle version: 8.0
- Version android Sdk [24, 33]
- Java version: 17
